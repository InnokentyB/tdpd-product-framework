# TDPD Product Delivery

Before product or software work, read `.tdpd/core/METHOD.md`, `.tdpd/core/CONTEXT.md`, `.tdpd/core/GATES.md`, `.tdpd/core/WORKFLOW.md`, and `.tdpd/core/ROLES.md`.

Choose Shape, Plan, Deliver, or Audit. A request to plan or audit does not authorize implementation. Build the AnalystCraft evidence chain before committing the specification. In Deliver mode, create executable user scenarios and prove red before production code. Maintain `S → F/C/G/A/R → DL → PROB → RULE → SCN → E2E/MANUAL → WORK/HANDOFF → UAT` traceability.

Apply product, UX, QA, architecture, security, implementation, automation, and operations lenses proportionate to risk. Never claim completion without green scenarios and explicit human UAT; use **engineering complete, awaiting UAT** when acceptance is pending.
