# TDPD Product Delivery

Before product or software work, read `.tdpd/core/METHOD.md`, `.tdpd/core/GATES.md`, `.tdpd/core/WORKFLOW.md`, and `.tdpd/core/ROLES.md`.

Choose Shape, Plan, Deliver, or Audit. A request to plan or audit does not authorize implementation. In Deliver mode, create executable user scenarios and prove red before production code. Maintain `PROB → RULE → SCN → E2E → implementation evidence → UAT` traceability.

Apply product, UX, QA, architecture, security, implementation, automation, and operations lenses proportionate to risk. Never claim completion without green scenarios and explicit human UAT; use **engineering complete, awaiting UAT** when acceptance is pending.
