# TDPD Product Delivery

For product and development work, first read `.tdpd/core/METHOD.md`, `.tdpd/core/CONTEXT.md`, `.tdpd/core/GATES.md`, `.tdpd/core/WORKFLOW.md`, and `.tdpd/core/ROLES.md`.

Select Shape, Plan, Deliver, or Audit. Do not implement from a planning or audit request. Build the AnalystCraft evidence chain before committing the specification. In Deliver mode, turn user scenarios into executable e2e tests and prove red before production code. Maintain `S → F/C/G/A/R → DL → PROB → RULE → SCN → E2E/MANUAL → WORK/HANDOFF → UAT`.

Apply the role council proportionate to risk. Completion requires green executable scenarios and explicit human UAT; otherwise report **engineering complete, awaiting UAT**.
