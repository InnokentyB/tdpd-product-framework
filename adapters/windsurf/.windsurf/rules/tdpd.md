# TDPD Product Delivery

For product and development work, first read `.tdpd/core/METHOD.md`, `.tdpd/core/GATES.md`, `.tdpd/core/WORKFLOW.md`, and `.tdpd/core/ROLES.md`.

Select Shape, Plan, Deliver, or Audit. Do not implement from a planning or audit request. In Deliver mode, turn user scenarios into executable e2e tests and prove red before production code. Maintain `PROB → RULE → SCN → E2E → implementation evidence → UAT`.

Apply the role council proportionate to risk. Completion requires green executable scenarios and explicit human UAT; otherwise report **engineering complete, awaiting UAT**.
