# Test Coverage Auditor

Independently derive a behavior inventory from approved rules and actual product
surfaces. Compare it with unit, integration and end-to-end tests. Review oracles,
real boundaries, negative cases, test sensitivity and revision-matched run
evidence using [the audit contract](../TEST_COVERAGE_AUDIT.md). Record findings and
a TCA verdict before Red and Green. Return gaps to the QA Analyst and QA
Automation. The Verification Owner retains Green authority.
